# Warehouse Ops Agent: front end

React + Vite + TypeScript + Tailwind + shadcn/ui. The chat talks to the FastAPI backend
through Vite's dev proxy (`/api` -> `http://127.0.0.1:8000`).

```
npm install        # once
npm run dev        # http://localhost:5173 (start the backend too: see ../CLAUDE.md)
npm test           # Vitest + Testing Library
npm run lint       # oxlint
npm run typecheck  # tsc
npm run build      # production build into dist/
```

`src/components/ui/` is generated by the shadcn CLI (`npx shadcn@latest add <name>`);
app code lives in `src/components/chat/` and `src/lib/`.
